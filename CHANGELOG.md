# CHANGELOG — TRAVELO

## [v4.0.0] — 2026-08-03
### Added
- **Root Architecture Shift**: Moved React app to repository root for optimal Vercel performance.
- **Mobile Scaling Core**: Implemented `clamp()` font scaling and responsive Silicon Glass padding.
- **Permanent Marker Accent**: Injected handwritten fonts into Dashboard and Missions for the 'Adventure Journal' vibe.
- **Zero-Failure Persistence**: Hard-coded LocalStorage engine to prevent network errors during client presentations.

## [v3.0.0] — 2026-08-03
### Added
- **Silicon Transparency UI**: 60px backdrop blur components across the entire app.
- **Squad Mail**: Functional internal messaging system (simulated delivery).
- **Brutalist Design System**: High-impact Bebas Neue headers and raw borders.
- **Memory Vault**: Support for photo uploads and captions in Explore.

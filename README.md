## 🔥 WHAT IS THIS?

Travelo is a **production-grade travel planning & expense splitting app** for elite squads who take trips seriously. Built with brutalist Silicon Transparency UI, it handles everything from itineraries to debt settlements — zero drama, all vibes. 

**v4.0 Update**: Architecture moved to root for maximum performance and lightning-fast Vercel deployment.

## ⚡ FEATURES

| Feature | Status | Description |
|---------|--------|-------------|
| 🗺️ Mission Board | ✅ LIVE | Create & manage trips with full squad |
| 💸 Expense Logger | ✅ LIVE | Per-trip logging with category tags |
| ⚖️ Min-Cash-Flow | ✅ LIVE | O(n log n) debt simplification algorithm |
| 💳 Payment Portal | ✅ LIVE | Brutalist checkout with card formatting |
| 📸 Memory Vault | ✅ LIVE | Photo upload, caption, delete |
| 📨 Squad Mail | ✅ LIVE | Internal messaging with sent history |
| ✈️ Logistics | ✅ LIVE | 6 booking portals — Indigo, MMT, IRCTC... |
| 🤖 AI Concierge (Tara) | 🔄 BETA | GPT-4o powered travel advice |

## 🎨 DESIGN SYSTEM

- **Typography**: Bebas Neue (headers) + Plus Jakarta Sans (body)
- **Glassmorphism**: 60px backdrop-blur Silicon Transparency
- **Palette**: #030303 black + #FF4D00 orange + #00F0FF cyan
- **Style**: Brutalist borders, massive headers, crispy copy

## 🚀 TECH STACK

- **Frontend**: React 19, Tailwind CSS, Framer Motion, localStorage
- **Backend**: FastAPI (Python), MongoDB Atlas
- **AI**: GPT-4o via Emergent LLM Gateway
- **Deploy**: Vercel

## 📦 SETUP

```bash
npm install && npm start
```
